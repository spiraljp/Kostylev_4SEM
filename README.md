## Постановка задачи

Цель работы — знакомство с HTML и CSS на примере верстки калькулятора. Необходимо оформить интерфейс в соответствии с индивидуальной темой.

Индивидуальная тема: **Grid-система планирования заданий**.

## Выполнение

Был создан калькулятор на HTML и CSS. Интерфейс содержит область вывода результата, набор кнопок арифметических операций, выпадающий список вычислительных узлов, ссылку на GitHub и блок с информацией об авторе.

Для оформления использованы стилизация контейнера калькулятора, кнопок, выпадающего списка и информационных блоков. Цветовая схема подобрана под тему вычислительной grid-системы.

## Дополнительное задание

В рамках дополнительного задания необходимо было изменить внешний вид кнопок калькулятора: переделать кнопки из округленных в квадратные.

Для этого были изменены CSS-свойства кнопок. Основное изменение связано со свойством `border-radius`: у кнопок был уменьшен или убран радиус скругления, благодаря чему элементы интерфейса стали квадратными и лучше соответствуют строгой стилистике grid-системы.
